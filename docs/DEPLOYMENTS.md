## Redeploying

```bash
cd packages/contracts
forge script script/Deploy.s.sol --rpc-url mezo_testnet --broadcast --private-key "$DEPLOYER_PRIVATE_KEY" --slow
forge verify-contract <factory> src/RePayAccountFactory.sol:RePayAccountFactory --verifier sourcify --chain-id 31611
cd ../.. && pnpm abi   # if contracts changed
```

Then update `packages/sdk/src/deployments.json` (`repay` block). `Deploy.s.sol` refuses any chain
other than 31611 and checks that `BorrowerOperations.musd()` matches the expected MUSD.
